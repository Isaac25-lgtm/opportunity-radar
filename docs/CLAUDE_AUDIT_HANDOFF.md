## What changed

| Area                     | Behavior on the audit branch                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Matching and browsing    | Free accounts can match jobs, internships and graduate programmes. Consultancies require Jobs. The feed, details, dashboard and scheduled alerts enforce the same rule. Listings outside a plan stay browsable. The feed keeps catalogue pagination after paid access ends. Restricted details name the unlocking plan even before profile creation. Dashboard ranking uses the same comparison as the feed. |
| Geography                | Fixed several regional and membership rules, including ECOWAS withdrawals, the Horn of Africa, Asia and southern Africa. The matcher asks for clarification on an ambiguous Congolese nationality. Suggested regions use the same Eastern Africa definition as the filter.                                                                                                                                   |
| Billing                  | A subscription grants access only during its paid period. Provider confirmation must match the expected amount exactly, including when an amount has a fraction of a cent.                                                                                                                                                                                                                                   |
| Notifications            | Alert pagination includes the listing ID, so a full page ending at a shared timestamp does not skip listings. The old cursor format still works. The inbox, dashboard and unread counts respect the in-app toggle. System notices remain visible. Tracked deadlines respect preferences. Withdrawn listings are excluded from the saved feed and saved-listing reminders.                                    |
| CV editing               | Saves and version restores from the editor carry the last confirmed revision. A stale edit stays in the tab with a message explaining how to preserve it. Updates and their version snapshots share one database transaction. Existing API clients can still save without sending a revision.                                                                                                                |
| Google sign-in           | Existing users sign in with their password and use **Settings → Connect Google** before first-time linking. Subsequent sign-ins use the provider identity. A signed-in user selecting another account receives an error. New accounts and their identity records are created together. Added checks on token audience and authorized party, and tightened the shared return-path validator.                  |
| Account data and tooling | Account export includes linked support messages and sign-in identities. Account deletion clears linked support messages, password resets, notification preferences and usage counters. Restored `npm run env:check`. It reads local Wrangler configuration, reports configuration status by name and exits unsuccessfully for missing required settings.                                                     |
